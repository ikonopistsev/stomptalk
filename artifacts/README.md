# Published measurements

This branch includes the performance summaries, selected CSV tables, command
manifests and textual perf reports for the measured parser implementation.
`../PERFORMANCE.md` is the cumulative index; `../SERVER_HANDOFF.md` describes
the integration contract and Clang/SSE2 build.

Full local experiment directories additionally contain builds, source copies,
raw perf.data, PGO counters, training corpora and external review transcripts.
Those generated files are not included in this commit. Links to omitted raw
files in historical reports refer to the original workspace artifacts.
