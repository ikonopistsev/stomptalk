# Сопоставимые сканеры — 2026-10-27

Изучены первичные исходники. Эксперимент написан самостоятельно; зависимости
и код перечисленных библиотек в stomptalk не добавлены.

- [simdjson: stage1 indexer](https://github.com/simdjson/simdjson/blob/master/src/generic/stage1/json_structural_indexer.h).
  Структурная маска превращается через trailing-zero count и сброс младшего
  установленного бита в массив uint32 offsets, используемый следующим этапом.
  Это прямой аналог предложения сначала разметить, потом разобрать. Его
  пакетная запись индексов допускает запас места в выходном массиве; такую
  предпосылку нельзя переносить в наш контракт без проверки вместимости.
  JSON-правила кавычек не заменяют STOMP escaping.
- [simdcsv](https://github.com/minio/simdcsv),
  [stage2](https://github.com/minio/simdcsv/blob/master/stage2-parsing.go).
  Первый этап обрабатывает 64 байта двумя AVX2-векторами и получает маски
  разделителей, кавычек и CR; второй извлекает поля из масок. Перенос состояния
  между блоками нужен для кавычек и CRLF. Репозиторий архивирован; интересен
  подход, а не подключение библиотеки. В отличие от offsets, маска компактна
  даже при большом количестве разделителей.
- [picohttpparser](https://github.com/h2o/picohttpparser/blob/master/picohttpparser.c).
  findchar_fast применяет SSE4.2 cmpestri для поиска первого кандидата.
  Есть отдельная проверка полноты секции; parse_headers затем разбирает поля.
  Это пример более простого поиска, а не доказательство выигрыша полной карты.
- [httparse AVX2](https://github.com/seanmonstar/httparse/blob/master/src/simd/avx2.rs),
  [SSE](https://github.com/seanmonstar/httparse/blob/master/src/simd/sse42.rs).
  Векторные проверки строят movemask и находят первую неподходящую позицию.
  Короткий остаток передаётся SWAR. Полный массив границ заголовков не строится.

Для сравнения концепций ширина всех экспериментальных загрузок одинакова:
SSE2, 16 байт. Отдельный переход на AVX2 следует измерять после выбора алгоритма,
иначе нельзя отделить эффект карты от эффекта ширины вектора.

Предварительная гипотеза: одна сохраняемая маска требует меньше состояния и
оставляет существующее дерево разбора; более крупная карта может окупиться
на множестве полей. Ни один из этих выводов о скорости не следует из чужих
результатов — нужны измерения полного stomptalk на одинаковых входах.
